# 批量重命名

WinShun 常驻插件。输入 `pl` 或 `cmm` 打开独立窗口。本地查找替换、智能整理、插入内容、自动编号和手动编辑，可选 AI 命名，先预览再执行并支持撤销。

作者：[Day / askd126](https://github.com/askd126) · 许可证：[MIT](LICENSE)

## 安装（社区脚本版）

这是符合本仓库规则的 **Python 源码版本**，与自行分发的内置环境安装包不同：不包含 EXE、DLL 或 Python 运行时。适用于 Windows 10/11 x64，需要 **Python 3.12+（含 Tcl/Tk）**。

1. 在插件库安装，或将本文件夹完整放到 `%LOCALAPPDATA%\WinShun\plugins\day.rename\`。便携版使用其实际插件目录。
2. 使用 WinShun 插件卡片显示的同一个 Python 解释器安装 `requirements.txt`，不要把依赖装到其他 Python 环境。以源码检出目录为例：

   ```powershell
   python -m pip install -r plugins/day.rename/requirements.txt
   ```

   如果 Python 位于别处，请用其 `python.exe` 完整路径代替 `python`。Tkinter 不通过 pip 安装，需在 python.org Windows 安装程序中包含 Tcl/Tk 组件。
3. 启用插件，在插件卡片填写模型配置（批量重命名的本地功能无需模型），输入 `pl` 或 `cmm` 使用。

启动入口 `bootstrap.py` 在依赖缺失时返回协议提示，不自动联网下载安装组件。源码更改后重新启用插件，或用 WinShun 开发者模式重载。更新同 id 插件前先停用旧版本；永久模型设置仍由 WinShun 管理。

## 模型设置

API 地址、模型名称和 API Key 的填写方式与 OpenAI Chat Completions 兼容服务一致。支持 Base URL 或完整 `/chat/completions` 地址，不预置服务商或密钥。OCR 需要支持图片输入的模型；批量重命名只需文本模型。

窗口内配置只在当前进程内有效；永久配置请使用 WinShun 插件设置，password 密钥由 Windows 凭据管理器保存。示例和源码不包含任何实际密钥。

## 五个功能页

- **查找替换**：按顺序应用多条规则；支持忽略大小写、Python 正则表达式及替换捕获组。留空查找框可禁用一条规则。
- **智能重命名**：默认提供本地空格整理、全角转半角、合并重复分隔符、删除开头编号、大小写转换。可选 AI 生成预览与本地规则分开，不会自动联网。
- **插入内容**：支持文本、序号、文件信息三种内容，开头、末尾或指定字符位置插入；位置从 0 开始，超出原名长度时追加。文件信息包括创建/修改日期、大小、扩展名、父文件夹和原文件名，仅读取元数据。文件信息是插入到原名称中的内容，可带前后字符；日期支持 YYYYMMDD、YYYY-MM-DD 和带时分秒的安全文件名格式。例如在末尾插入 _ + 创建日期，可把 报告.PDF 预览为 报告_20261024.PDF。
- **自动编号**：支持阿拉伯数字、中文小写/大写、英文小写/大写字母，可指定前后字符、起始、步长、补零位数；保留原名、替换原名或自定义模板。字母序号 1=A、26=Z、27=AA，中文序号范围 0–99999999。`{n}` 为编号、`{name}` 为原名；编号按当前列表顺序生成。默认按名称自然排序（2 在 10 前），可切换倒序或添加顺序。
- **手动编辑**：双击文件行编辑，或「批量编辑名称」每行输入一个名称。手动编辑始终输入完整名称（含扩展名）。在其他页双击会把当前预览带入手动页。在手动页对文件列表按 Ctrl+V，可把 Excel 一列或多行文本从所选行向下填充；不选择行时从第一行开始。

默认保留文件最后一个扩展名；勾选「同时修改文件扩展名」才将它纳入本地规则和 AI 输入。文件夹始终按完整名称处理。添加文件夹只改文件夹本身，不递归添加或改名内部内容。可以一次选择多个文件，文件夹可多次添加或一起拖入。列表支持 Delete 移除选中行，不会删除磁盘文件。

每批本地规则最多 5000 项，AI 最多 200 项。不能同批选中父文件夹及其内部项目；请分批操作。暂不支持符号链接、目录联接或同批中的多个硬链接。

## AI 命名（可选）

右上角「AI 模型设置」输入与 OCR 相同格式的 **OpenAI 兼容 API 地址、模型名称、API Key**。支持 Base URL 或完整 `/chat/completions` 地址；文本模型即可，无需视觉能力。远程必须 HTTPS，本机 localhost / 127.0.0.1 / ::1 可用 HTTP，本地免密服务填任意占位密钥。

窗口配置仅保留在内存；永久配置使用 WinShun 插件设置，password 密钥由 Windows 凭据管理器保存。不会自动复制 OCR 的密钥，也没有内置服务商、模型或密钥。

进入智能页，填写命名要求，点击「AI 生成预览」。仅发送当前文件名（或不含扩展名的名称）和你输入的要求，不发送完整路径或文件内容。模型生成后必须再次检查预览并点击执行。AI 返回的数量、Windows 名称与名称冲突均需通过本地校验；改变列表、排序或规则会丢弃迟到的 AI 结果。接口不会跟随 HTTP 重定向，错误不显示密钥或服务的原始响应。

## 执行与恢复

执行时再次检查源文件、重名、目标占用、保留名称、非法字符和父子路径冲突。每个项目先在同文件夹改为随机临时名，再改为目标名，因此支持文件名互换及仅修改大小写。Windows 改名操作拒绝覆盖已存在的目标。

执行前写入 `dataDir/last-rename.json`，记录原路径、新路径、临时路径和文件身份信息，不记录文件内容或模型配置。普通失败会尝试恢复原名称；遇到占用等导致恢复失败或程序中断，可重启后点击「撤销 / 恢复」。恢复时核对文件身份及原名是否被占用，不会覆盖后来创建的文件。恢复记录可在你恢复文件前保留，不要手动移走相关文件或删除记录。此机制不是整个文件系统的原子事务；停电、外部程序移动文件或网络盘断连时，仍可能需要根据记录处理。

## 权限

| 权限 | 用途 |
|---|---|
| ui | 独立界面、文件选择器、文件拖放 |
| clipboard:read | 用户按 Ctrl+V 时读取资源管理器文件列表，或手动页的多行名称文本，不读取剪贴板历史 |
| files:read | 读取用户所选路径的名称和元数据，不读取文件内容 |
| files:write | 执行改名、撤销，以及保存插件数据目录的恢复记录 |
| network | 仅用户点击 AI 生成时连接用户配置的服务；本地规则不联网 |

不申请 processes，不启动子程序。关闭窗口仅隐藏；退出 WinShun 才结束常驻进程。

## 源码、开发与验证

本目录包含全部运行源码、依赖清单、MIT 许可证和离线回归测试。`main.py` 负责窗口，`rename_protocol.py` 负责 JSON-RPC，`rename_core.py / ai_names.py` 负责核心功能。

```powershell
python plugins/day.rename/bootstrap.py --standalone
python plugins/day.rename/bootstrap.py --self-test
python -B -m unittest discover -s plugins/day.rename/tests -v
python tools/check.py --changed day.rename
```

`--self-test` 不联网、不读取剪贴板，也不修改用户文件。回归测试的文件操作只发生在临时目录，远端 API 使用模拟响应；不以单元测试代替真实模型及系统拖放/截图验证。会在桌面上显示并缩放窗口的测试需显式设置 `WINSHUN_VISIBLE_LAYOUT_TEST=1`，默认跳过。

仓库 CI 在维护者合并后按标准脚本插件格式发布 `.wsplugin`。该包仍需以上 Python 依赖，不会下载或启动外部二进制程序。
